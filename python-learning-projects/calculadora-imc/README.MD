# 🩺 Calculadora de IMC

Projeto desenvolvido em Python para consolidar os conhecimentos adquiridos durante o **Mundo 1 de Python** do **Curso em Vídeo**, ministrado pelo professor Gustavo Guanabara.

## 📖 Sobre o projeto

A Calculadora de IMC realiza o cálculo do Índice de Massa Corporal (IMC) a partir do peso e da altura informados pelo usuário, exibindo a classificação de acordo com a tabela da Organização Mundial da Saúde (OMS).

Este projeto foi desenvolvido com foco na prática de lógica de programação e estruturas condicionais.

## 🚀 Funcionalidades

* Cadastro do nome do usuário.
* Entrada do peso e altura.
* Cálculo automático do IMC.
* Classificação do resultado.
* Exibição de um relatório organizado no terminal.

## 🛠️ Tecnologias utilizadas

* Python 3

## 📚 Conceitos praticados

* Entrada e saída de dados (`input` e `print`)
* Variáveis
* Tipos de dados (`str`, `float`)
* Operadores aritméticos
* Estruturas condicionais (`if`, `elif` e `else`)
* Formatação de strings (f-strings)
